# وصيل | WASEEL

تطبيق Android Native لمساعد مكالمات شخصي محلي، بواجهة عربية RTL وهوية كحلية وزرقاء مستوحاة من الصورة المرجعية.

## الحالة الحالية — مرحلة التأسيس
تم إنشاء ملفات Gradle وManifest وموارد التصميم الأساسية، واجهة لوحة تحكم أولية، ملف تعليمات JSON داخل assets، محرك قواعد عربي أولي، فحص أولي لمحرك التعرف على الكلام والنطق، نقطة تكامل InCallService، كيانات Room وDAO وقاعدة البيانات، ودليل تحويل المكالمات واختبارات وحدة أولية.

بعض ملفات XML للشاشات أُنشئت كقوالب واجهات أولية، وليست جميعها مرتبطة بعد بأنشطة أو وظائف نهائية. لا تعتبر هذه النسخة إصداراً Production أو APK جاهزاً.

## البناء
- Android Gradle Plugin: 8.7.3
- Kotlin: 2.0.21
- JDK: 17
- compileSdk/targetSdk: 35
- minSdk: 26

افتح المشروع في Android Studio ثم نفّذ Gradle Sync وبعدها:
```bash
./gradlew test
./gradlew assembleDebug
```

## الخصوصية والعمل المحلي
- لا يحتوي المشروع على OpenAI أو Gemini أو Claude أو API محادثات خارجي.
- لا يوجد إرسال صوت أو نص إلى خادم سحابي.
- ملف `app/src/main/assets/waseel_assistant.json` هو مصدر إعدادات قواعد المساعد الافتراضية.
- محرك القواعد ليس نموذجاً لغوياً توليدياً.
- يجب التحقق على الجهاز من أن التعرف الصوتي يعمل فعلياً على الجهاز دون إنترنت. لا يتم التحويل إلى خدمة سحابية عند عدم توفره.
- بيانات الصوت العربي واللهجة السعودية تعتمد على محرك وحزم الجهاز.

## قيود Android والاتصالات
وجود `InCallService` لا يمنح التطبيق تلقائياً صلاحية الوصول إلى صوت طرفي المكالمة. يلزم اختيار دور تطبيق الهاتف المناسب وتوافق إصدار Android والجهاز. لا يعلن التطبيق أن SIM auto-answer أو المحادثة الثنائية قد اكتملت قبل اختبارها على جهاز حقيقي. تحويل المكالمات يعتمد على شركة الاتصالات. لا يدعم Android واجهة عامة رسمية للرد الآلي على مكالمات WhatsApp الشخصية.

## قاعدة البيانات
Room entities الحالية تشمل المكالمات والمحادثات والرسائل والملخصات وجهات الاتصال والقواعد والإعدادات ومهام المتابعة. يلزم استكمال عمليات الربط والمعاملات والحذف المتسلسل والتقارير قبل اعتبارها مكتملة.

## الاختبارات
توجد اختبارات أولية لتطبيع النص العربي ومطابقة القواعد والرد الاحتياطي. لم يتم بعد تأكيد نجاح Gradle build أو تشغيل الاختبارات على بيئة Android فعلية.

## الأمان
لا تضع مفاتيح أو كلمات مرور أو ملفات توقيع داخل المستودع. لا تُفعّل التسجيل الصوتي افتراضياً. يجب تطبيق الموافقات والالتزامات النظامية والمحلية قبل حفظ المحادثات.
